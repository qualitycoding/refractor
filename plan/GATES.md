# Human gates (G-###)

At a gate the implementer halts, writes `GATE-<id>.md` at repo root with the evidence bundle, commits, pushes, and waits.
It resumes only on a reply containing one of the allowed responses verbatim.

## G-001 — not applicable
`math`/`computational` profiles inactive (plan/PROFILE.md).

## G-002 — External or irreversible action (guard)
- **Trigger:** any step or deviation that would publish a GitHub Release, tag `v*`, upload binaries anywhere public,
  make the repository public (if private), or submit to a plugin marketplace. **No planned step triggers it** (A-011).
- **Evidence bundle:** CI run URL (all jobs green), artifact list with SHA-256, licence file (AGPL-3.0), T-053 output,
  signed-off G-003.
- **Questions:** Publish? Under which version?
- **Allowed responses:** `proceed: <version>` → implementer creates tag/release exactly as named; `stop` → halt, nothing published.

## G-003 — Listening & IP sign-off (required, ends S-013)
- **Trigger:** end of S-013 (all automated tests green in CI except any explicitly listed as blocked).
- **Evidence bundle (`GATE-G-003.md`):**
  1. CI run URL and per-OS artifact download links.
  2. Rendered demo WAVs in `demo/` (generated by `tools/render_demos` from S-012; 48 kHz, 24-bit) for the eight
     presets in `demo/PRESETS.md`: noon chorus; slapback (Tracking 0.2); fourth-down harmony; third-up harmony +
     octave; Magic low (repeats); Magic high ascending trails; Magic high descending; max self-oscillation.
     Inputs: `demo/input/*.wav` synthesised by the same tool (plucked-string Karplus-Strong phrase, chord, bass line).
  3. Current `Calibration.hpp` values and their bounds (notably `kWindowSamples` 1024 → lag 31–208 ms vs chord clarity; 2048 doubles the lag range; clarity depends only on lag, lag × resolution = 1; `kWetCeiling`).
  4. Screenshot of the editor (`demo/editor.png`) and T-053 output.
- **Questions for the human:**
  a. Does the character match your expectation of the pedal? For each preset: ok / too clean / too dirty / wrong lag / wrong pitch.
  b. Any calibration changes (name the constant and value within bounds)? In particular: is the lag range right, and are chords clear enough at high Tracking (`kWindowSamples`)?
  c. Is the UI free of anything resembling the original pedal's trade dress?
- **Allowed responses:**
  - `proceed` → go to S-014.
  - `calibrate: <CONST>=<value>[, ...]` → S-013b: apply values (must satisfy static_asserts), re-run CI, re-render demos, re-open G-003.
  - `proceed-with-rescope: <text>` → log text in DEVIATIONS.md, apply only if it does not touch frozen tests/interfaces; else halt BLOCKED.md.
  - `stop` → halt; leave branch as is.
- **Limit:** after 3 `calibrate` rounds without `proceed`, the implementer writes BLOCKED.md summarising the feedback (fidelity may need reference captures, R-001).

## G-003 — blind listening gate `rendering-regression`

- **Trigger step:** S-LISTEN after applicable implementation/review prerequisites and before downstream packaging/retrospective work.
- **Evidence bundle:** `GATE-G-003.LISTENING.md` and `listening/G-003/round-001/` containing the machine-readable `result.json`, ordered locked answers, exact score and one-sided binomial p-value, side-bias count, verbatim findings, reference/candidate provenance and checksums, pair-builder settings, render manifest, demo definitions, and `SHA256SUMS`.
- **Frozen primary condition:** 12 matched onset pairs, initial seed `20261106`, common RMS −23 dBFS, 1.0 s clips, 10 ms fades, 44.1 kHz PCM-24 WAV, pass at ≤8/12 with no unresolved qualitative finding. Maximum three total rounds; rounds 2 and 3 use the initial seed +1000/+2000.
- **Questions for the human:** ordered A/B reference choices for all 12 pairs, then the repository-specific demo/weak-spot questions in `plan/LISTENING-AMENDMENT.md`.
- **Allowed responses:** `proceed`, `calibrate`, `iterate: <notes>`, `proceed-with-rescope: <text>`, `stop`.
- **Plan branches:** see `plan/LISTENING-AMENDMENT.md`; downstream resume is `S-014`. `stop` and `blocked` leave this gate open with the reason and next prerequisite recorded.
